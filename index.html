Frequently Asked Questions

Quick answers about BeginnerAman, flagship systems, and engineering stack

Who is Aman Vishwakarma (BeginnerAman)?

Aman Vishwakarma, known online as BeginnerAman, is an AI-Native Product Architect and Systems Builder from India. He has created 35+ open-source repositories spanning offline-first Windows desktop software, local networking tools, retail POS applications, and progressive web apps.

What is ADrop by BeginnerAman and how fast is it?

ADrop is an open-source, 100% offline local file-sharing tool built as a Windows alternative to AirDrop. It transfers unlimited files between Windows PCs and phones at 150+ MB/s over Wi-Fi hotspots or USB tethering using QR code pairing, requiring zero internet and no mobile app install.

What offline systems and desktop tools has BeginnerAman built?

His flagship offline systems include ADrop for high-speed file transfer, AirDeck for wireless Windows hardware control, smart-file-sync with a 1,906 files/sec Win32 DMA sync engine, VastraFlow for offline garment retail POS and thermal billing, RenameSense with WAL rollback batch renaming, and StorageOrganizer for MD5 deduplication.

How does BeginnerAman build and engineer software?

He follows an AI-Native Product Architecture workflow, focusing on system design, Win32 and network logic, and user experience while orchestrating frontier AI models including Google Antigravity, Claude, Gemini, and DeepSeek across Python, PySide6, FastAPI, WebSockets, SQLAlchemy, and JavaScript.
